# Cat vs Pickles

A small browser game: help the cat dodge falling pickles.

## Play

Open `index.html` in any browser. No build step or dependencies.

- **Move:** ← → or A / D, or drag / tap on touch screens
- **Lives:** 3 — a pickle hit costs one
- **Bonus:** catch the glowing 🐟 for +50
- Pickles fall faster the longer you survive. Best score is saved in your browser.
